# antiG-QS — Releases

Public release channel for **antiG-QS**, a standalone Revit add-in for model-based quantity surveying (NZIQS elemental takeoff, BOQ export, quantity variations). This repo hosts release assets only — no source code.

Independent of antiGGGravity: its own Hardware ID activation, its own update channel. Installing or updating antiG-QS has no effect on any other antiGGGravity product, and vice versa.

## Install

1. Download `AntiGQS_Installer_AllVersions.zip` below.
2. Unzip it.
3. Run `install.bat` — it detects which Revit versions (2022–2027) are installed and deploys antiG-QS to the correct folder for each.
4. Restart Revit.

To uninstall, run `uninstall.bat` from the same unzipped package.

## Current Version

See [`version.txt`](version.txt). antiG-QS's **Check Update** button reads this file to know whether a newer release is available, and downloads `AntiGQS_Installer_AllVersions.zip` from this repo when you confirm.
